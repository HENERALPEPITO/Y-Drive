# 🧩 Pokémon Browser

A modern, responsive web app for exploring and searching Pokémon using the [PokeAPI](https://pokeapi.co/).

## 🚀 Features
- **Browse Pokémon** – View Pokémon in a responsive grid (20 per page)  
- **Search** – Find Pokémon by name (exact or partial)  
- **View Details** – Display ID, weight, and sprite  
- **Pagination** – Navigate with Previous/Next buttons  
- **Responsive Design** – Optimized for desktop and mobile  

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- Vanilla JavaScript (ES6+)  
- PokeAPI  


## 💡 Features
- **Browse:** Use the Previous/Next buttons to navigate through Pokémon  
- **Search:** Enter a Pokémon name and press **Enter** or click **Search**  
- **View Details:** Click **View Details** on any Pokémon card  
- **Clear Search:** Click **Clear** to return to browsing mode  

## 🧠 API
This is an assessment that uses the [PokeAPI](https://pokeapi.co/) for Pokémon data.
